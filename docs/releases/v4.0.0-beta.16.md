# PSP v4.0.0-beta.16

## Docker 相对挂载源统一为目录

- 在 `v4.0.0-beta.15` 的 GitHub 交互式 Node 安装功能基础上，重新合入 NAS Docker 挂载修复。
- 生成的 Compose 中，所有 `./xxxx` 宿主机路径都只代表目录，不再直接绑定任何相对文件路径。
- 私有凭据保存为 `./config/node-credential.txt`，Compose 只读挂载 `./config:/run/secrets/passwall-node:ro`。
- 容器通过 `PSP_NODE_CREDENTIAL_FILE` 读取目录内的凭据；文件缺失或不是普通文件时会拒绝启动。

## 默认使用可见的宿主机数据目录

- SQLite 数据库、下载的核心、生成的核心配置及运行状态默认映射到 `./data:/var/lib/passwall-node`。
- 启用 Docker 远程升级时，Agent 与隔离升级器通过 `./upgrades:/run/passwall-node-upgrades` 共享升级暂存及回滚数据。
- 新模板不再创建 Docker 命名卷；备份整个项目目录即可保留 Compose、`./config` 中的凭据和持久化数据。
- 已使用命名卷的现有部署不会自动迁移；若手动替换 Compose，须先把旧卷内容复制到 `./data`。
