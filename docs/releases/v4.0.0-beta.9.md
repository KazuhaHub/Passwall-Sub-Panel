# PSP v4.0.0-beta.9

## 3X-UI 3.8.0 兼容修复

- 3X-UI 3.8.0 开始允许负数 `subSortIndex`。PSP 更新入站时现在保留所有非零排序值，避免把面板中的负数排序重置为 1。
- 当前适配器已在全新的 3X-UI 3.8.0 / Xray 26.9.9 面板上验证状态、入站、客户端、共享客户端、并发写入、设备限制、配额上限和 REALITY 扫描路径。
- 3X-UI 3.8.0 的 TUIC v5 sidecar、AmneziaWG outbound 和原生 UDP hopping 仍不属于 PSP 当前的 3X-UI 功能范围。

## REALITY 注意事项

Xray 26.9.9 对 REALITY 要求 ML-KEM-first 握手。PSP 的 Mihomo 输出会在检测到该内核时使用 `chrome` 指纹和 `support-x25519mlkem768`；已知不兼容的 sing-box REALITY 节点会从该格式中省略。升级前请确认订阅客户端和备用节点。

## 升级与兼容性

本版为 Pre-release，仅发布 PSP，不自动升级线上面板、节点或代理内核。升级前请备份数据库和配置；3X-UI 3.8.0 首次启动会执行上游的模板和数据库迁移。

当前运行时兼容上限仍为 3.7.0。已发布的 beta.1–beta.8 不包含本次负数排序修复，兼容清单的数字匹配也不能区分 `v4.0.0-beta.N` 与 `v4.0.0`；待版本范围可以准确区分修复版本后再提高上限。

Docker 精确标签为 `ghcr.io/kazuhahub/passwall-sub-panel:v4.0.0-beta.9`；滚动标签 `beta` 会跟随最新发布，`latest` 仍仅指正式版。
