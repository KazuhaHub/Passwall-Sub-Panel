# PSP v4.0.0-beta.6

## 安装界面与反馈

- 新增服务器默认选择完整名称 Passwall Node；主表单仅保留类型、名称、安装方式和更新频道，备注与技术说明默认折叠。
- 安装／重装界面聚焦审核版本、一行命令、复制反馈和当前状态；手动步骤、私有文件与版本细节放入高级选项。必要迁移阻塞及确认仍然可见。
- 普通安装、3X-UI 转换与旧节点注册共用短命令。完整下载并检查语法后才执行，不流式执行响应；命令只携带限时私有下载地址，不携带长期节点凭据。
- 接入 Passwall Node `v0.0.1-beta4`：六阶段安装反馈、终端下载进度及有时限的 agent 启动检查。安装器完成只表示进程已启动，不代表节点同步、代理内核或真实代理就绪。

## 入站编辑修复

- PSP 已保存的受管配置，在同步等待、失败或漂移时仍可编辑，不再因 agent 暂时无观测配置而显示“不支持协议”。运行时与订阅的收敛判据没有放宽。
- 配置加载失败显示可重试错误，不打开伪造的编辑表单。非 SS-2022 Shadowsocks 不再错误转成 VLESS；不支持的协议或方法不会提供保存操作。
- 保留既有服务器、节点、凭据、精确版本、分组和流量记录；频道选择不会自动安装或升级。

## 兼容性与部署

保留已审核 Node beta3 的精确重装支持，新增 beta4；版本选择仍须来自已核验的正式发行资产。
同步 S-UI 1.6.2 的现有适配器兼容说明，不新增可选能力或无损迁移承诺。

本版为 Pre-release。Docker 精确标签为
`ghcr.io/kazuhahub/passwall-sub-panel:v4.0.0-beta.6`；`beta` 为最新发行频道，`latest` 仍只指正式版。
发行本身不会修改线上服务器或自动重装节点。升级前请备份数据库与配置，升级后检查服务器连接、
已应用配置／内核和真实客户端流量。
