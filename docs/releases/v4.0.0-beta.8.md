# PSP v4.0.0-beta.8

## 节点问题更易处理

- 默认只显示重要问题，普通内核启动记录移入“诊断”；可切换查看全部记录，不删除历史。
- 同台服务器的相关消息合并为简短摘要与处理建议，完整技术日志默认折叠在详情中。
- 支持分组勾选、全选本页及详情内逐条选择，批量“确认已查看”提供进度和结果；失败记录可重试。仅操作选中的原始记录，不跨页、不自动修复，也不把已查看当作已恢复。

## 服务器更新提示与通知修复

- 修复 beta7 将 Passwall Node 版本误报为可升级到 3X-UI 的通知及铃铛计数。
- Passwall Node 版本列按已保存的 Stable／Beta 频道提示已审核、已发布的新版本；点击后仍需在既有弹窗确认升级。
- S-UI 增加官方稳定版本提示与发行页面链接，仍需在服务器上手动升级。
- 安装及升级图标统一为带托盘的配套样式，英文入口统一为 “Install / Reinstall”。

## UDP／QUIC 默认配置

默认组显示顺序为“节点选择 → UDP控制 → QUIC控制”。UDP 默认 DIRECT，QUIC 默认跟随 UDP，仍可分别选择代理、直连或拒绝；规则匹配仍先 QUIC 再普通 UDP。

DIRECT 不等于禁用 UDP，而是使用本地出口 IP，可能与 TCP 代理出口不同。仅更新已知、未自定义的官方默认规则，保留管理员自定义内容及客户端已保存的选择；已有客户端仍选代理时，可手动切换 UDP 组。

## 升级与兼容性

本次仅发布 PSP，不更改 Node 协议、代理内核或数据库 schema；Passwall Node 依赖仍为 `v0.0.1-beta4`。无需重装或重新添加服务器、节点，现有身份、凭据、配置及历史流量保持不变。

本版为 Pre-release，Docker 精确标签为 `ghcr.io/kazuhahub/passwall-sub-panel:v4.0.0-beta.8`；`beta` 跟随最新发行，`latest` 仍仅指正式版。升级前请备份数据库和配置；发布不会自动更新线上部署或执行远程升级。
