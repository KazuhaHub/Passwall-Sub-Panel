
## V3 final stable release

This release preserves the business code and database model of `v3.9.2-beta.20`
(`081b209d67873f8ab78f69aba5d6a24cf294404e`). Release preparation only updates the
preferred Go compiler to 1.26.8, both Docker runtimes to Alpine 3.23.5, and the
release/verification pipeline. It does not contain the V4 native-node backend,
remote-node upgrade UI, or V4 database migrations.

Back up the database and configuration, including encryption/signing keys and
custom rule sets/templates/locales, before upgrading. For SQLite, stop PSP before
copying its database; for MySQL/PostgreSQL use a consistent backup. Do not replace
your existing configuration or data directories with files from the archive.

`ghcr.io/kazuhahub/passwall-sub-panel:v3.9.2` identifies this release; `:latest`
tracks stable releases and is updated to V3.9.2. V4 testing uses its explicit
`v4.0.0-beta.1` tag (or the moving `:beta` channel), never `:latest`.
