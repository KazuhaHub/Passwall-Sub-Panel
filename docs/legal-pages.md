# 隐私与协议页：实现与验收

本功能按节点访问控制最终实施计划的阶段 3、§8 和 S21–S23 交付。默认关闭；同意机制只提示普通用户，不阻断订阅。

## 已实现的发布存储

`legal_documents` 的 `(kind, locale, version)` 唯一索引保存不可变文档。种类为 `terms` 或 `privacy`，语言使用规范化语言标签，正文最多 60,000 UTF-8 字节。每次发布新增一行，不覆盖旧正文；历史读取按版本降序分页，每页最多 50 行。

非法 UTF-8 和 NUL 字节在写入前拒绝，避免不同数据库接受不同正文。中文恰好 60,000 字节可发布，超过一字的情况被拒绝；NUL 输入先复现错误接受，再加入校验。

`legal.consent_version` 是两份文档、所有语言共用的单调版本。首次发布将其置为至少 1；之后只有重大变更递增。文档与同意版本在同一事务提交，失败整体回滚。全局状态行串行化并发发布；文档版本唯一冲突仅重试一次，其他数据库错误不冒充冲突。

普通设置保存只能初始化缺失的同意版本为 0，不能降低、提高或用旧草稿覆盖它；首次设置保存与发布交错时也保持已发布值。加载不接受调用者提供的同意版本默认值。发布成功后使共享设置缓存失效，并递增缓存代数，避免旧读取永久写回缓存。

系统设置 GET 返回 `legal_enabled` 与只读 `legal_consent_version`。PUT 允许显式修改开关，旧客户端省略或发送 null 时保留现值。请求中的同意版本忽略，即使它来自旧页面、被伪造或不是整数，也不能改变已发布版本。服务端继续返回持久版本，避免把草稿值显示成生效值。

设置保存期间发生发布时，保存响应会再次读取持久同意版本；数据库保留新版本而响应仍回显旧值的情况也由真实 SQL 交错测试覆盖。

`legal.enabled` 的存储默认 false。公开 HTTP 与自助注册已接通，页面和登录后提示界面仍待完成。

## 已实现的同意与注册存储

`legal_consents` 以 `(user_id, consent_version)` 为主键，只保存同意时间和服务端确定的 `register` / `prompt` 来源，不保存 IP。重复同意同一版本不会改写时间或来源。普通用户在功能启用、有已发布同意版本、且没有同意当前或更高版本时为 pending；管理员和操作员不进入 pending。

注册请求接受 `accepted_consent_version`。新建待验证账号、无需验证直接注册、重新注册待验证账号这三条路径均使用注册专用 SQL 写入方；当前版本来自数据库，不能用服务层缓存代替。注册写入方与发布接口锁定同一全局状态行，在单个事务内检查版本并写入账号或密码、同意记录。过期或未提交同意返回 409 `legal_consent_outdated`，不创建账号、不修改已有密码和令牌版本；同意记录写入失败也整体回滚。

重新注册时事务再次确认账号仍是待验证的普通账号，已激活或因其他原因停用的账号不能因此被改密。密码使用原有 bcrypt 参数，同意事务提交后才进行邮件或外部节点操作。缺少原子写入能力时返回不可用，不退回普通账号写入。默认关闭、启用但尚未发布、已有文档但关闭时保持原注册行为，不生成版本 0 的同意行。管理员创建和 SSO 路径保留原写入，后续通过提示补充同意。

同意记录不按时间删除；应用每小时清理已删除账号的同意记录，启动后的首轮也执行此清理。重大变更的影响计数包含所有普通账号，包括已同意当前版本及暂时停用的账号。

## 公开读取与用户接口

公开读取仓库在同一事务内持有发布状态行的共享锁，再选择最新正文及语言回落。请求语言优先；zh-TW 缺失时先尝试 zh-CN；之后依次尝试 en-US、zh-CN，仍不存在返回未找到。请求语言规范化为语言标签。默认关闭、尚未发布或请求种类缺失均未找到；不会将已缓存的旧正文与新全局同意版本拼接。公开 DTO 不包含管理员 ID 或内部文档 ID。

`GET /api/legal/:kind?lang=` 位于认证之外，返回文档及 `data_collection`。ETag 是整个 JSON 的 SHA-256，包含语言回落、全局同意版本和实际采集设置；另一文档的重大变更或保留期修改也使缓存失效。成功响应及 304 均带 `Cache-Control: no-cache` 和 ETag。先检查当前启用状态和正文存在，再检查条件请求，关闭或不存在时不能以 304 保留旧页面。

采集设置在公开文档事务内直接从持久库读取，只输出明确的公开字段。`sub_log_retention_days`、`auth_event_retention_days` 为 0 表示永久；连接历史与风控标记使用实际运行时默认及上下限，0 分别为 7、90 天。`hwid_captured` 反映全局采集开关，HWID 摘要随订阅日志保留。风险判定覆盖间隔使用实际 `risk_assessment_refresh_minutes`；管理员复核无按时间过期，在删号后的每小时清理中删除。此阶段分支尚未集成访问控制采集，`access` 是空数组，前端隐藏这些行；不能据此声称其他访问控制候选分支也没有采集。

`GET /api/auth/methods` 增加 `legal:{enabled, consent_version}`；`GET /api/user/me` 增加 `legal_pending` 和 `legal_consent_version`，同意状态以真实普通用户角色与持久记录计算。pending 不阻止读取 profile。`POST /api/user/me/legal/accept {consent_version}` 使用已认证用户 ID，不能通过请求里的其他 ID 修改别人；过期返回 409，关闭返回 404，staff 返回 403。相同版本重复提交保持第一次记录。法律状态读取失败不会虚构已同意状态；订阅路径没有法律同意门禁。

管理接口位于原有管理员认证路由内。`GET /api/admin/legal/:kind?before_id=&limit=` 返回跨语言的不可变版本历史，每页最多 50 行、按内部 ID 降序，响应为 `{items, next_before_id}`。`POST /api/admin/legal/:kind {locale, content, consent_bump}` 的发布者来自认证身份，请求不能指定其他发布者。`GET /api/admin/legal/affected-users` 返回重大变更涉及的普通用户计数。正文过长返回 400 `legal_content_too_large`，一次重试后仍有版本冲突返回 409 `legal_version_conflict`。
