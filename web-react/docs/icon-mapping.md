## Look-alike glyphs, deliberately different

The sync tasks page shows all of these at once, so they must not share a shape: `IconRefresh` (circular arrows, refresh a list), `IconSync` (two-way arrows, the sync tasks page), `IconRetry` (a repeat symbol, re-run a task) and `IconReset` (an undo arrow, back to the default). `IconDot` is a filled dot; `IconCircle` is the ring.
